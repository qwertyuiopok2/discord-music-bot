# discord-music-bot
### 1. Настройка в Discord Developer Portal
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications).
2. Создайте новое приложение (**New Application**) и добавьте бота в меню **Bot**.
3. Дайте боту административные права в разделе Privileged Gateway Intents.
4. Скопируйте **Token** бота.
5. Пригласите бота на сервер через **OAuth2 URL Generator** (выберите scopes: `bot` + permissions: `Administrator`)
6. Откройте скачанный вами файл затем откройте файл бот.py с помощью pycharm.
7. На 22 строке замените текст на свой токен
8. Откройте терминал и имортируйте нужные библиотеке командами pip install discord.py / pip install yt-dlp / pip install aiohttp
9. https://www.gyan.dev/ffmpeg/builds/packages/ffmpeg-2026-08-30-git-818cecc6e1-essentials_build.7z по этой ссылке скачай ffmpeg
10. Распакуйте zip архив в диск ц 
11. Нажмите на клавиатуре кнопку виндовс и напишите "изменение системных переменных среды"
12. Нажмите на кнопу переменные среды.
13. Где системные переменные найдите переменную PATH!!!!!!!!!!!!!!!!!!!!!!!!!!!!
14. Нажмите по ней 2 раза потом на кнопочку создать и вставьте этот текс C:\ffmpeg-2026-08-30-git-818cecc6e1-essentials_build\bin и ок.
